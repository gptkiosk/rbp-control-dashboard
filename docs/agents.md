# Agents and lightweight runtime status

The shared prototype retains adapters for Hermes, OpenClaw, Claude Code and Codex and adds a common lightweight-runtime interface. MCD assigns reviewed routes and owns retries/handoffs; native models do not silently substitute.

- **OpenClaw / Hermes:** contributors can use these tools to research, prepare stories, implement bounded changes and produce evidence in their approved workspace. Discord planning requires profile pairing; draft/read MCP access cannot dispatch or publish. See [agent workflow](development/agent-workflow.md).
- **Claude / Codex subscriptions:** useful on the Mac coordination/development host. Do not assume those subscription applications are available as local Pi runtimes.
- **ZeroClaw:** local adapter and free-only/model-pinning work exists. Recorded offline/VM rehearsal does not establish live-provider behavior, full approval/recovery conformance or physical-Pi performance.
- **PicoClaw:** partial adapter; required usage/model/tool evidence and runtime conformance remain incomplete. Do not select it based on unmeasured results.

No production Pi runtime selection or real-hardware certification is claimed. Live model tests require explicit free-only/cost policy, suitable key access and pre-dispatch enforcement. Provider/runtime binaries are separate projects, not bundled or endorsed by RCD. Preserve their license/trademark notices when distributing your own deployment.
